La motivacion para desarrollar este RAG fue basicamente para proporcionarle a un amigo, una herramienta para su aplicacion mobil que sirva como un buscador, pero combinando la capacidad de un LLM, como asi tambien una busqueda dinamica y eficiente en una base de datos local.
Este desarrollo fue mejorado, pero queda subido solo la version original para resguardar la integridad de la aplicacion mobil previamente mencionada.

----

The motivation for developing this RAG was primarily to provide a friend with a tool for his mobile application that would function as a search engine, combining the capabilities of an LLM (Local Management Tool) with dynamic and efficient searching of a local database.
This development has been improved, but only the original version remains uploaded to safeguard the integrity of the aforementioned mobile application.
